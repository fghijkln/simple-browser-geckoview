# Quad9 DNS 查询数据边界

核查日期：2026-10-05。简浏览 2.2.0 将 GeckoView DoH URI 配置为 `https://dns.quad9.net/dns-query`。该配置将正常递归 DNS 查询交给 Quad9；DoH 加密客户端至 resolver 的传输，但 resolver 必须处理查询名称并返回结果。

Quad9《[Data and Privacy Policy](https://quad9.net/privacy/policy/)》版本 1.1（发布日期 2026-06-24）称，服务处理查询时会在易失内存中短暂持有回复地址，以完成响应和计数，之后删除；政策表示不会持久收集或记录用户 IP 地址，也不会用替代标识符识别个人用户。

政策同时说明，Quad9 可在持久档案中保留全部或部分聚合统计。维度可包括 resolver 地点、网络前缀与 ASN、地区、QTYPE、DNS 标志、响应码、协议、IP 版本、网络类别及过滤匹配状态；另可能保存每个查询标签的计数、首次/最近时间。Quad9 称这些计数不含个人可识别信息，且不与单个用户关联。政策也说明，针对由某威胁情报提供者识别的恶意域名，可能向该提供者反馈有限计数、时间及部分统计维度，但不含个人可识别信息；其政策称不会分享 NXDOMAIN 查询名称。

Quad9 FAQ 表示其公共递归服务不记录客户端 IP，同时提醒异常网络攻击等情况可能适用独立政策。以上均为服务商公开的数据处理声明，不是本应用的独立审计结论。TLS 不隐藏目的 resolver、连接时间或字节量；DNS-over-HTTPS 也不隐藏后续网页连接目标或地址信息。

应用未访问 Quad9 泄漏测试站、未发送测试查询。RFC 8484 请求/失败回退测试使用本机 loopback HTTPS mock。GeckoView 的设备端解析路径未验证，设置界面也据此显示“GeckoView DNS 路径未验证”。
