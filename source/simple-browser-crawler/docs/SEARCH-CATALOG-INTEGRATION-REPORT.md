## 模板核验状态（仅 500 个 PDF 条目）

| 状态 | 数量 | 可执行分段模板 |
|---|---:|---|
| verified | 264 | 仅采纳对应分段 JSON 的 `search_template` 原值 |
| unclear | 171 | 不提供分段可执行模板 |
| not_available | 65 | 不提供分段可执行模板 |

每个 PDF 条目保存原始模板状态、证据 URL、证据说明和访问限制；字段 `search_template` 对非 `verified` 一律为空。旧目录兼容 URL 单独标记为 `legacy_compatibility`，这是为保持既有 21 项行为而保留的既有模板，不是新分段核验结果。新增 PDF-only 条目只有 `verified` 才会有运行时 `urlTemplate`；其他条目可浏览/筛选但提交查询时不会执行来源猜测 URL。

264 条 `verified` 来源模板中，261 条可按应用允许的 HTTPS 单一占位符格式运行；ID **403、409、464** 的模板还含外部 `{API_KEY}` 占位符，原始 `search_template` 与证据照样保留，但运行时 `urlTemplate` 为空，避免缺凭据或把 API 模板当作免配置网页搜索。

已核验模板包含查询参数和路径片段两种形态。loader 只检查 HTTPS、主机、单一占位符、无凭据/片段，并允许占位符位于 URL path 或 query；路径片段按 UTF-8 路径安全编码。站点专有 slug 规则、POST 表单和动态交互式查询不会被推造。

## 费用与账户门槛

逐项保存 PDF 费用分类、费用附录置信度/日期、PDF 运行状态、模板段访问说明及原证据链接。API key、credits、订阅或服务配置门槛不会作为免费公开网页搜索呈现。原 21 项按兼容要求保留旧访问类别；新增条目优先采用核验说明中明确的核心免费/账号/付费要求。门槛不明的新增条目保守归入非免费类别并在 `accessNote` 标明“尚未确认、不等于已证实收费”，而不是静默标成免费。

7 个要求自建/部署/建立索引的项目列在非免费类别以免被误认为直接可用的免费公共搜索；逐项备注明确说明这不等于已证实收费。选择器行增加 API、部署、账号和费用不确定提示；仍维持原三类访问筛选。

## 验证限度

- 本次未访问或运行任何查询 URL；未运行 Gradle wrapper、Java 测试、包内项目脚本或构建。
- 所有模板检查均为本地字符串/URI 结构校验，不证明服务此刻在线、查询结果可用、地区无阻拦或实际费用/登录政策。
- PDF 费用与运行状态按所给提取数据保存；存在未列明、模糊或附加 API/会员条件时以逐项备注为准。路径模板使用通用 URL 编码；可能仍受站点 slug/搜索语义影响。
- 兼容保留的旧 21 项运行时 URL 以原目录为准，即使新模板状态是 `unclear`/`not_available`；其新核验字段仍为空模板，不将旧模板标记成 verified。
